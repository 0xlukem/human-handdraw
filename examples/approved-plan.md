# Example approval packet

## Message

Language: Spanish

`idea → acción`

The message shows an idea becoming concrete through movement rather than presenting a branching diagram.

## Static composition

```text
        idea
          ╲
           ╲ rough curved arrow
            ╲
          ( acción )
```

The upper-right and lower-left remain open for the subject in the underlying footage.

## Reveal order

1. Write `idea`.
2. Add a two-line underline to emphasize the starting concept.
3. Draw the curved arrow and loose arrowhead.
4. Write `acción`.
5. Draw an imperfect circle around `acción`.

## Timing

- 0.0–1.8 s: `idea`
- 1.8–2.4 s: underline
- 2.5–4.1 s: arrow
- 4.2–6.8 s: `acción`
- 6.9–7.6 s: circle
- 7.6–10.0 s: completed reading hold

## Style

Warm-white base strokes, one muted yellow accent on `acción`, fixed organic imperfections, no audio, 1080 × 1920 at 30 fps.
